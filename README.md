## Offline Testing
 
### Setup
Run the following setup. This is required only for the first time. If you have done this already, you can skip to the next section. 
1. Install Jekyll: `gem install bundler jekyll`
2. Install dependencies in the Gemfile: `bundle install`

### Serving
Serve the blog locally: `bundle exec jekyll serve`. The blog will be hosted in `localhost`.
